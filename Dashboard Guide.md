# NFL Dashboard Using Shiny
## Overview
* This is the first dashboard that I've ever made and there are tons of things that I want to do with it (or have it do). I recently got some great advice from someone, they said "start with having it do one thing, then add something else". This was excellent advice, especially since I think of so many things I want to add or do with it.
* I'm not sure if I want this dashboard to be a general one that I can use for various things or I want it to be more specific for the data that I'm working with. Actually, I think after I make one with my specific dataset in mind it'll be a lot easier to create a more general one.
